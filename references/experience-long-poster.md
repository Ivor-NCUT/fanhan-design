## 值得保留的视觉语言

| 维度 | 原图观察 | 新设计如何迁移 |
| --- | --- | --- |
| 情绪 | 温暖阳光、生活现场、人的表情与动作，轻松而有邀请感 | 先选课程对应的真实生活处境与光线，避免抽象科技光效和无关豪华场景 |
| 配色 | 暖沙金封面、奶油白底、薄荷绿信息区；橙色标题、黄色强调、局部青绿 | 迁移底色与强调色的职能及对比关系；另建适合新课程的色盘，不只换颜色就声称原创 |
| 字体 | 封面青绿标题富有笔画姿态；内页黑色粗中文无衬线与橙色重点交替，正文较轻 | 具体字体未经核实，不断言字体名。主标题醒目完整，正文可读，少量表现性字体只承担情绪 |
| 排布 | 大人物与场景、紧凑信息、金句和留白交替，圆角与不规则边界连接段落 | 编排内容的阅读节奏，避免从头到尾同款卡片；长宽比例作节奏参照，不靠空白强凑长度 |
| 人物 | 摄影肖像、局部探入画面的头像、抠图人物与场景叠放 | 真人身份必须保留真实照片；调整裁切、尺度、视线和叠放，不生成替代本人面孔 |
| 图标 | 放大镜、情绪表情、小物件图标与标题或信息绑定 | 图标表达发现、体验、情绪等具体意义；统一尺度与材质，不能靠随机 emoji 增加丰富度 |
| 装饰 | 布幅、鸡眼扣与牵绳、回形针、便签、相片拼贴、吊挂卡片与彩色挂钩 | 让装饰成为承载信息的物件，具备固定、悬挂、遮挡等可信关系；不把所有装饰塞进每一段 |
| 层次 | 背景现场、中景人物、前景纸张/布料、原生文字共同组成画面 | 图像生成提供无字场景和独立材质，HTML/CSS 与 SVG 负责文本、路径、遮罩与可调整组合 |

## 逐段看什么

1. **首屏与宣言**：暖色肖像与青绿标题形成冲突感，人物跨入浅色曲线/布料区域；下接黄色悬挂布幅、回形针便签与小照片。学习开场的情绪、主次与材质过渡，不拆散课程名称。
2. **发起人与定义**：黑橙大标题、放大镜、小圆角照片与大幅抠图人物形成不对称构图；浅绿说明和黄色引用把文字分成可扫读层级。人像不能挤压或盖住正文。
3. **邀请与权益**：大标题与右侧人物呼应，薄荷色双列信息区承担密集说明，底部摄影与黄色标注打破重复。卡片高度随内容调整，文字区域约占可用框的 80%，不把它机械理解为字形占满 80% 面积。
4. **玩法场景**：车站/候车空间中的招牌、挂钩信息牌、座椅与人物，构成一整幅可探索的现场。学习“内容成为场景中的物件”，为新主题重新选择现场与物件，而不是复刻同一车站。
5. **适用人群**：橙黑标题、边缘人物、浅绿说明卡与大表情交替，情绪识别先于小字说明；控制长段落与图标之间的距离。
6. **收尾报名**：草地、水面与木杆布旗承接邀请情绪，价格和入口落在清楚的实体载体上。替换成已核实的报名信息，不能复用参考二维码或把未确认价格写成事实。

## 编码执行与验收

同时遵循 [编码视觉闭环](operations/coding-visual-loop.md)：先看图与内容、规划当段、生成独立素材、编码、实际渲染、看图修正，完成一段再继续下一段。图像与文字分离；正文用 HTML 文本或 SVG text，不烘焙进背景。阴影、边缘、纸张与人物遮挡也要在渲染图中检查。

每段检查：是否有明确阅读主线；素材是否服务内容；场景与信息的比例是否有变化；文字是否足够大且与背景有对比；矩形是否存在大片无效空白。整图缩览检查节奏，再按手机阅读宽度与局部原尺寸检查文字、抠图、装饰边缘。视觉丰富度不以素材个数衡量，更不能以模糊小字换取。

归档验收：原图真实保留，分段可打开，Skill 与资产索引能找到本条；仅发布方法说明，原图保留本地。这次是参考归档与规则静态核验，不代表已实测生成新的整张海报。
