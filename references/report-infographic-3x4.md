# 信息可视化长图 3:4（报告解读 / 趋势分析）

用户于 2026-10-30 推荐一组即刻动态配图，认为其信息可视化呈现很好，指定**报告解读、财报解读、趋势分析**类图片优先采用此排版。以下只记录参考图中实际可见的特征；标注「待确认」的为目测估计。

## 适用场景

- 财报 / 研报 / 行业报告的分章解读，一组多张连续发布（参考组为 9 张，页码连续编号）。
- 趋势分析、结构拆解、争议逐条核对等「数据 + 判断」型内容。
- 不适用：情绪型海报、单一金句、人物 / 产品主视觉。

## 规格

- 画幅 3:4 竖版，参考原图 1500×2000 px。
- 页边距约为画宽的 4–5%（待确认），左右对齐同一纵向基线。
- 背景为暖米白纸色，无纹理、无大面积色块底。

## 版式结构（自上而下）

1. **品牌栏**：左上品牌字标（参考为「N 内森聊AI」，替换为泛函标识），下方一条细灰分隔线。
2. **眉题**：小号强调色字，格式 `页码  系列名 + 报告期 ｜ 本页章节`，如「07 宇树科技 2026 Q3 财报解读 ｜ 客户与场景」。
3. **主标题**：大号宋体 / 衬线粗体，两行；第一行为问题或主题，第二行直接给结论（如「人形机器人卖给谁？ / 七成以上是科研教育」）。**一页 = 一个核心洞察**，标题即结论。
4. **口径说明行**：标题下一行小号灰字，用竖线分隔数据口径、时间范围、披露来源。
5. **模块区**：以 `A / B / C / D…` 浅灰字母编号的小节，每节含小节标题（中号衬线）+ 图注副标题（小号灰字：时间 · 指标口径）+ 图表。常见网格：一行通栏 + 一行二分栏 + 一行三栏 KPI。
6. **KPI 卡**：2–4 个大数字并排，细竖线分隔；大号衬线数字（深蓝或棕橙）+ 加粗一行释义 + 灰字补充（同比、往年对照）。
7. **编号要点**：底部 1/2/3 列表，每条「**粗体短判断：** 数据证据」，强调色序号。
8. **资料来源**：页脚小号灰字，写清引用材料并附「仅供研究交流，不构成投资建议」类免责。

变体：「争议拆解」页改为 01–10 编号列表，每行 = 序号与短标签（左）+ 粗体论点与数据证据（中）+ 右侧描边结论标签（如「口径混淆」「待年报验证」），结论标签用强调色描边区分成立 / 存疑。

## 字体

- 标题、小节标题、KPI 大数字：衬线 / 宋体粗体，具报刊感。
- 眉题、正文、图注、坐标：无衬线黑体，小字号；数据数值加粗。
- 字号层级约 5 档：主标题 ≫ KPI 数字 > 小节标题 > 正文 > 注释 / 来源（待确认具体字号）。

## 图表规范

- 用到的图表：100% 堆叠横条（结构占比）、横向条形排名（前五大客户、渠道）、柱状 + 折线双轴（金额与费率）、分组柱状（年度对比）、整宽分段比例条（资金分配）、对比表格（行 = 品类，末列为描边判断标签）。
- 数值标签直接写在条内（白字）或条端（深色字），百分比保留两位小数，**不依赖坐标轴读数**。
- 图例为小方块 + 文字，置于图表左上；坐标轴与网格极简或省略。
- 每张图配一行口径副标题（期间 · 指标 · 单位）。
- 无 3D、无阴影、无渐变、无装饰图标。

## Do / Don't

- Do：标题直接写结论；每个数字都注明口径与期间；用一个暖色点出关键数据；页脚写来源；多张连续编号、眉题保持一致。
- Do：区分「事实 / 推断」，在要点或标签中明确写出「未披露」「口径混淆」等边界。
- Don't：一页塞多个无关结论；用饱和彩虹色；用饼图堆砌；省略数据来源；大面积色块背景。
