# 设计语言

## 源码分析清单

读取页面时记录这些证据：

- `font-family`、字体文件、展示字与界面字的角色分工
- `font-size`、`line-height`、`font-weight`、`letter-spacing`
- CSS 变量中的语义色，不只抄页面截图里的十六进制颜色
- 容器圆角、段间距、最大宽度、列比例和断点重排
- transform、sticky、overflow、scroll trigger、文字拆分和路径动画
- 同一组件在桌面、平板、手机上的构图变化

## 默认视觉语法

| 角色 | 默认值 | 用法 |
|---|---|---|
| 阅读场 | `#FFFFEB` | 长段内容、大面积呼吸区 |
| 沉浸场 | `#034F46` | 事实、产品信息、深色章节 |
| 推进场 | `#1A1A1A` | 对话、状态切换、行动区域 |
| 回声色 | `#F0D7FF` | 转写结果、按钮、短标签 |
| 状态色 | `#FFA946` | 少量数字或待确认状态 |

展示字：

- 默认字体：阿里妈妈东方大楷
- 常用字号：64–120
- 行高接近字号，允许少量收紧
- 句子短，留白大，不堆装饰

产品字：

- 使用系统无衬线字体
- 常用字号：16–28
- 字重 600–700
- 每行尽量短，信息名称和值分层

## 构图语法

- 场景容器圆角 40–80。
- 双栏优先使用 `1.5:1` 或 `1:1.75`。
- 章节间距 64–128。
- 斜向语句带保持 4–8 度倾角。
- 圆形节点贴近语句带末端，表达录音、确认或状态转移。
- 允许局部越界，不能遮住关键信息。

## 深层借鉴标准

合格的借鉴能说清来源代码里的结构证据，也能解释成品里的对应决定。只复刻暖白、紫色、圆角卡片，视为表层模仿。

避开这些做法：

- 复制原站标志、专属插画、产品截图或原文
- 把每块信息装进同尺寸白卡片
- 三种比例共用一张构图
- 为了“科技感”添加渐变光球、网格背景和无意义发光
- 使用未验证的字体名，交付时再让平台自动替换
