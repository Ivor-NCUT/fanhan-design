# 洛言

这套风格来自职业辅导服务长图与 12 页横屏演示的实际迭代。先确定一页的主判断和可公开的证据，再选择组件。历史横屏样板：[PNG](examples/luoyan-landscape.png) · [SVG](examples/luoyan-landscape.svg) · [完整 HTML](examples/luoyan-landscape.html)；历史竖屏样板：[PNG](examples/luoyan-portrait.png) · [SVG](examples/luoyan-portrait.svg) · [完整 HTML](examples/luoyan-portrait.html)。PNG/SVG 是后来依据公开 HTML 重制的封面或结构预览；完整设计以 HTML 为源。示例里的图片、聊天与联系入口均为公开占位素材，不代表真实人物、案例或可扫描的二维码。

## 视觉语法

| 角色 | 值或方法 |
| --- | --- |
| 阅读底 | `#f3f3f3` 暖灰白 |
| 主强调 | `#00b667` 明绿；标题深绿 `#00673d` |
| 正文 | `#202020`；次级文字 `#777` |
| 价格场 | `#202020` 到 `#123e2b` 的单向深色过渡 |
| 展示字 | 阿里妈妈东方大楷；只用于大标题、观点和服务主句。仓库不再分发字体文件，运行前核实本机字体授权与安装。 |
| 信息字 | 清晰的系统中文无衬线；用于价格、事实、标签和操作。 |

核心组件：细绿竖线刊头、分色书写标题、绿渐变胶囊标签、白线与半透明内框、暖橙与冷蓝交叠的背景、黑边案例图、淡灰网格、黑绿价格场。组件可复用，构图须按画幅重新组织。

## 16:9 横屏

- 固定设计画布 `1280 × 720`。投屏适配用整体缩放，打印时每个画布独立成页。
- 每页只表达 1～2 个重点。服务页左侧为主判断与说明，右侧为案例；不要把纵向长图直接裁成幻灯片。
- 刊头与标题先形成独立区，再留至少约 30px 的可见距离放内容框。价格场同样执行。
- 展示字按实际字体测量。两行口号无多余标点；正文避免单字尾行，必要时改文案或缩小字号，不靠强制溢出。
- 两张证据图上下叠放时保持同宽、左右边缘对齐；需要错位时要有明确的阅读理由。
- 人像用靠上放置的圆角矩形，避免无意裁去人物主体。截图保持原有遮挡、打码和来源语义，不能通过提取底图恢复遮挡内容。

## 竖屏长图

- 基准内容宽度 `400px`。开头是主张与人物，随后是四项服务、证据图和行动区。
- 服务卡复用背景、白色内框和编号胶囊；每一节的图片尺寸与内容密度按实际材料调整。
- 长图中约每 800–1200px 出现一次节奏变化。网格可提示转场，价格区以深色结束。
- 手机窄屏优先保持阅读尺寸；不要把 `400px` 画布缩到文字不可读。

## 交付检查

1. HTML 文字、卡片、线条和价格块可编辑；图片仅用于真实照片、案例或图像素材。
2. 检查所有图片是否有授权，私聊、联系人、二维码和敏感截图在公开版本中只用占位素材。
3. 回读每页标题与正文的换行、标题到内容框的间距、图片裁切、页码和打印尺寸。
4. 横屏与竖屏共享颜色、字级角色和组件，不共享机械缩放的构图。
